07 / On-device intelligence · Inclusive interfaces

SignSpeak Junior.

A child-friendly sentence builder with speech output and locally running word suggestions.

01 / OVERVIEW

The problem

Young users can benefit from an interface that lets them construct and hear short sentences without relying on a keyboard or a cloud AI service.

The approach

The application uses large vocabulary cards, sentence playback, and an on-device helper. Its compact intent model and transition model rank possible next words and help reorder short sentences.

My contribution

Developed the companion mobile application and its communication-focused interface, as described in my project announcement.

03 / ENGINEERING

Inside the implementation

  • Picture or emoji vocabulary cards and quick phrases.
  • Local intent prediction and next-word ranking.
  • Favorites, recent words, and customizable vocabulary.
  • Parent settings and Android speech output, with a browser speech fallback.

The engineering consideration

The helper is packaged with the interface rather than calling a remote language model. Suggestions can use the current sentence, favorites, and recent vocabulary without sending the sentence to a cloud AI endpoint.

04 / SCOPE & STATUS

What this work demonstrates

A communication prototype, not a clinical product. The repository preserves an APK and extracted web bundle, not the original Gradle project. Picture mode may request online images; it is not a fully offline image library.
